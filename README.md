# Niko Pet 3D

Windows 11 的 3D Minecraft 猫耳女巫桌宠。方案阶段，等待确认后开始写代码。

## 它会是什么样

- 64×64 **Slim 双层** Niko 皮肤，3D 方块模型，固定 3/4 视角。
- 慵懒嗜睡：在任务栏上方散步、呼吸、眨眼、东张西望、坐下、睡觉、伸懒腰。
- 偶尔掏出 Minecraft 面包啃几口，掉屑、打嗝、冒爱心。
- 屏幕变暗（亮度 ≤ 阈值）时举起 Minecraft 火把，暖光照亮角色；长按也能切换。
- 单击摸头；**按下压扁、松开弹回**（和鲸鱼娘同款手感 + Ya1/Ya2 点击音）。
- 原地长按 1.5s 切火把；继续按到 3s 关闭：紫色末影粒子爆发、停留约 1.2s、隐藏到托盘。
- 全屏时身体藏到屏幕外，偶尔从随机边缘探头；平时正常在底部走动。
- Ctrl+Alt+P 拍照，带桌面背景保存到 `图片\NikoPet`。
- 桌面上没有任何文字/气泡/名字牌。

## 技术

Electron 44 + Three.js 0.186 + skinview3d 3.4.2 + TypeScript + electron-vite；打包便携 exe + NSIS 安装包。
