# Niko Pet 3D 永久规则候选（供选择）

这 100 条是候选，不因出现在本文件而生效。仅 R001 已由用户明确选定并写入项目根目录 `AGENTS.md`。请回复要采用的编号，例如 `R001、R014、R063`；选定后再合并进 `AGENTS.md`，并检查与原规则的冲突。

## 模型与视觉

- R001 永久使用 64×64 Minecraft Slim 双层皮肤；允许兼容原 UV 的高级骨骼与次级动作（已选并写入 AGENTS.md）
- R002 原始 Niko 皮肤只读，所有表情变化使用运行时副本
- R003 每次改模型都核对内外层、手臂宽度和贴图朝向
- R004 骨骼升级先保留原站姿作为可回退基线
- R005 动作不把方块身体拉伸成非 Minecraft 造型
- R006 角色尺寸和镜头构图对每个档位保持一致
- R007 睡眠与坐姿保持头脸可辨认
- R008 火把、面包等道具始终对齐对应手部骨骼
- R009 所有新增视觉效果先在透明桌面窗口实拍
- R010 桌宠主体永不绘制文字、气泡或昵称

## 架构与依赖

- R011 主进程负责窗口、托盘、系统集成和文件访问
- R012 渲染进程负责动作、WebGL、声音和粒子
- R013 预加载桥只暴露经过验证的最小 IPC 接口
- R014 可复用的状态机和计算逻辑放在 shared 目录
- R015 功能模块按责任拆分，避免单文件持续膨胀
- R016 修改设置字段时同步更新解析、界面和行为
- R017 所有异步动作都提供取消与恢复路径
- R018 保持单实例锁，禁止产生第二只桌宠
- R019 新依赖先说明体积、维护状态和替代方案
- R020 固定运行环境版本变更需先做独立兼容验证

## 动作与物理

- R021 所有动作通过同一行为状态机协调优先级
- R022 角色移动必须有可调惯性与平滑停止

- R024 走路步频跟随真实屏幕移动速度

- R028 角色空闲时的小动作应稀疏且可关闭
- R029 全屏探头只显示可点击的头部区域
- R030 动作中断后道具、音效和粒子都要收尾

## 交互与桌面
