# 决策记录（问答汇总）

> 记录 2026-10-20 的五轮问答，供实现和验收对照。若后续改主意，以新消息为准，并更新本文件与 `PRD.md`。

## 1. 方向

| 问题 | 选择 |
|---|---|
| 技术栈 | Electron + Three.js |
| 项目起点 | 新建 3D 项目，旧 2D 只做参考 |
| 模型 | skinview3d + 自定义动画 |
| 视角 | 固定 3/4 斜视角 |
| 活动范围 | 屏幕底部任务栏上方左右走 |
| 尺寸 | 首次启动向导里选（80–500，默认 220） |
| 性格 | 慵懒嗜睡 |
| 额外动作 | 坐下/睡觉、看/追鼠标、摸头/点击反馈、拖拽挣扎/落地、挥手/跳舞/转圈、呼吸/眨眼/东张西望（**没有选气泡台词**） |

## 2. 暗处、火把、面包

| 问题 | 选择 |
|---|---|
| 暗处判定 | 屏幕亮度/夜间模式 → 后续细化为“亮度 ≤ 阈值（默认 30%）” |
| 火把效果 | 手持火把 + 暖色光晕 + 火光摇曳；点燃/熄灭音效；**只照亮角色模型** |
| 火把时长 | 举 10–20 秒，然后放回 |
| 面包 | 从物品栏/背后掏出，啃 3–4 口；掉屑 + 咀嚼音；吃完打嗝 + 爱心；纯随机，无饥饿 |
| 食物触发 | 低频随机，不做饱食度 |
| 附加系统 | 只选拍照模式；不做心情/精力/久坐/天气/换肤/多宠物/AI |

## 3. 手势、关闭、粒子

| 问题 | 选择 / 补充 |
|---|---|
| 点击音效 | 鲸鱼娘「小黄鸭」Ya1（按下）+ Ya2（松开） |
| 长按反馈 | 角色**不变色**；周围产生 Minecraft 紫色粒子；无进度 UI |
| 长按时长 | 1.5 秒 |
| 关闭含义 | 隐藏到托盘，可再打开 |
| 紫色粒子 | 末影人/传送门紫粒子；向上飘散、带重力/拖尾；关闭后保留 1–2 秒再消失 |
| 火把触发 | 亮度 ≤ 阈值自动 + 手动长按切换 |
| 单击动作（最终） | **单击 = 摸头**；**原地长按 = 切换火把**；**长按并拖动 = 拖拽角色** |
| 关闭手势（最终） | **两段式**：长按 1.5s 切火把；继续按到 3s 关闭；2.4s 起紫色粒子聚集 |

| 全屏行为 | 身体藏在屏幕外，偶尔探出脑袋，大部分时候不出现；**仅全屏时**；平时正常底部走动 |
| 探头位置 | 随机边缘 |
| 压扁/回弹 | **和鲸鱼娘一样**：按下变扁，放开弹回来 |

## 5. 关键复刻参数（鲸鱼娘挂件）

来源：`%USERPROFILE%\.dsh\profiles\desktop\node_modules\dsh-whale-widget\assets\whale-widget.js`

| 项目 | 值 |
|---|---|
| 压扁 | `scaleY(0.88) scaleX(1.05)` |
| 变换原点 | `50% 100%`（脚底） |
| 回弹 | `transform .22s cubic-bezier(.34,1.56,.64,1)` |
| 极短点击 | 至少保持 32ms 压扁起点再回弹 |
| 按压音 | `Ya1.mp3`（当前 duck 组） |
| 松开音 | `Ya2.mp3`（当前 duck 组） |
| 松开音提前量 | 40ms（若两段音有重叠，按 40ms 对齐） |
| 音效组 | `duck`（小黄鸭） |

3D 实现时，以角色脚底为 pivot 设置 `playerObject.scale`；在 press 时快速到 `(1.05, 0.88, 1.0)`，release 用同样的 220ms 过冲曲线回 `(1,1,1)`。

## 6. 仍待用户确认的 3 个假设

1. 拖拽松手后落回目标显示器任务栏上方，而不是停在任意位置。
2. 一直暗时自动火把最多每 10 分钟一次；手动长按不受限。
3. 向导昵称只用于托盘提示/照片文件名，桌面不显示。

## 7. 解释与冲突处理

- “长按 1.5s 切火把”与最初“长按关闭”冲突 → 采用**两段式**：1.5s 火把，3s 关闭。用户已确认。
- “单击切火把”与“单击摸头”冲突 → 以最终版“单击=摸头，长按=火把”为准。
- “点击会收起/拿出火把”与“长按切火把”冲突 → 以最终版“原地长按切火把”为准；单击不再切火把。
- “屏幕暗了”最初选亮度/夜间模式 → 最终明确为亮度阈值；不依赖 Windows 夜间模式状态，避免深色主题常驻误判。
- “不要名字/完全无文字”与向导“昵称”冲突 → 昵称保留为内部字段（托盘提示/照片文件名），桌面零文字。
- “全屏时身体藏起来”只适用于全屏；平时仍然在任务栏上方走动，满足“正常行走”。

## 8. 技术环境补充（2026-10-20 实机）

- **Electron 版本锁定 44.7.0**。本机 44.9.1 在 Windows 11 26200 上 `app.whenReady()` 不触发，`--no-sandbox` / `--disable-gpu` / `--single-process` / Electron 33 均未绕过；DSH 自带 44.7.0 runtime 运行本项目正常。
- 透明窗口 + WebGL alpha + skinview3d Slim 双层已在 44.7.0 runtime 下实机确认。
- 相机缩放最终选 `viewer.zoom = 0.55`（420px 画布，宠物约 220px 高）。
- 压扁/回弹已用 CDP 真实鼠标事件验证：press `(1.05, 0.88)`，release 220ms 过冲后回到 1。
