# Niko Pet 3D — 产品需求（方案 v0.1）

> 状态：**待你确认**。确认后进入 M0，先做 1 天技术验证，再按里程碑开发。
>
> 角色：Niko（猫耳女巫），素材为用户提供的 `niko.png`：64×64、RGBA、Slim（3px 手臂）、双层皮肤。
>
> 平台：Windows 11 x64。技术栈：Electron + Three.js + skinview3d + TypeScript。

---

## 1. 一句话产品

一个慵懒、安静、偶尔犯困的 3D Minecraft 猫耳女巫桌宠：在任务栏上方散步、伸懒腰、偷偷吃面包；屏幕变暗时举起火把；按下会被压扁、松开弹回；长按可以切换火把，继续按住会碎成紫色粒子并躲回托盘。

---

## 2. 已确认的设计决定

| 维度 | 决定 |
|---|---|
| 技术栈 | Electron 44 + Three.js 0.186 + skinview3d 3.4.2 + TypeScript + Vite |
| 项目起点 | 新建 `niko-pet-3d`；旧 Python/PySide6 2D 版只作行为参考 |
| 模型 | skinview3d 渲染 Slim 双层皮肤；不用 Blender/glTF |
| 视角 | 固定 3/4 斜视角；走路时左右转向 |
| 活动范围 | 屏幕底部、任务栏上方左右走；拖拽可跨显示器，松手落回目标屏底部 |
| 尺寸 | 首次向导选；80–500px，默认 220px |
| 性格 | 慵懒嗜睡、安静；低频动作 |
| 额外动作 | 呼吸/眨眼/东张西望、坐/睡、看/追鼠标、摸头、拖拽挣扎/落地、挥手/跳舞/转圈 |
| 文字 | **桌面上完全不显示文字**：无气泡、无名牌、无状态；设置窗口/托盘菜单除外 |
| 点击 | 单击 = 摸头/开心反应；按下压扁，松开弹回（和鲸鱼娘同款） |
| 长按 | 原地按住 1.5s = 切换火把；继续按到 3s = 关闭（隐藏到托盘） |
| 拖拽 | 按住约 250ms 后可拖；长按并拖动 = 拖拽角色；长按不动 = 火把 |
| 火把触发 | 亮度 ≤ 阈值（默认 30%）自动触发；原地长按也可手动切换 |
| 火把表现 | 右手持火把、暖色点光**只照亮角色**、火光摇曳、火星、点燃/熄灭音效；不压暗桌面 |
| 面包 | 偶尔从物品栏/背后掏出面包，啃 3–4 口，掉屑、咀嚼音、打嗝、冒爱心；无饥饿数值 |
| 关闭 | 长按 3s 后紫色粒子爆发；粒子再停留约 1.2s；宠物隐藏到托盘；托盘可再打开 |
| 粒子 | 末影人/传送门紫粒子，向上飘散，带重力/拖尾；关闭时全屏扩散 |
| 音效 | 打包本机 Minecraft Java 1.20.1 原声 + 鲸鱼娘 Ya1/Ya2 点击音；默认音量 40% |
| 全屏 | 仅全屏时：身体藏到屏幕外，偶尔从**随机边缘**探头；平时正常底部走动 |
| 拍照 | 全局 Ctrl+Alt+P；冻结当前动作；带桌面背景截图；存到 `图片\NikoPet` |
| 托盘 | 显示/隐藏、设置、拍照、退出；单实例；开机自启默认关 |
| 附加系统 | 只做拍照模式；不做心情/饱食/番茄钟/天气/多宠物/AI 聊天 |
| 交付 | 便携 exe + NSIS 安装包 + 源码 |
| 素材范围 | 仅本地自用；允许打包 Niko 皮肤、Minecraft 原声/贴图、鲸鱼娘点击音 |
| 开发节奏 | 先方案确认，再按 M1–M4 里程碑实现并汇报；用本机 Codex CLI 驱动 |

## 3. 桌面交互

### 3.1 手势状态机

只响应鼠标左键；透明区域不拦截桌面点击。

| 输入 | 结果 |
|---|---|
| 按下 | 播放 Ya1；角色以脚底为轴压扁：`scaleX 1.05`、`scaleY 0.88`；开始计时 |
| 按住 ≤ 250ms 后移动 | 进入拖拽；窗口跟随光标；四肢下垂、轻微摆动 |
| 原地按住 1.5s | 切换火把（点燃/熄灭音效）；继续按住进入“可关闭”阶段 |
| 按住约 2.4s | 紫色粒子开始在角色周围聚集 |
| 按住 3.0s | 关闭：粒子爆发，角色消失，窗口保持全屏约 1.2s 播放粒子，然后隐藏到托盘 |
| 未拖拽/未长按时松开 | 单击 → 摸头/开心反应（歪头、闭眼、爱心粒子、猫呼噜）；播放 Ya2 |
| 拖拽中松开 | 落到当前显示器任务栏上方，播放落地缓冲；播放 Ya2 |
| 长按 1.5s 后松开（不到 3s） | 只切换火把；播放 Ya2；不关闭 |
| 移动超过 1.5s 后再移动 | 不进入拖拽，保持“长按关闭”判定（避免误操作） |

> 压扁/回弹参数直接复刻鲸鱼娘挂件：`transform-origin: 50% 100%`；回弹 220ms，缓动 `cubic-bezier(.34,1.56,.64,1)`。3D 中以脚底为轴的 `scale` 实现。

### 3.2 点击穿透与置顶

- 透明、无边框、无阴影、任务栏不显示、始终置顶。
- 空白像素点击穿透到桌面；只有角色的可见/可交互区域接收鼠标。
- 不抢当前窗口焦点；设置窗口正常接收键盘。
- 关闭/隐藏后托盘图标保留；托盘“退出”才真正结束进程。
- 全屏应用之上不挡画面：见 §6。

### 3.3 托盘与快捷键

- 托盘菜单：显示宠物 / 隐藏宠物、设置、拍照、退出。
- 全局快捷键：`Ctrl+Alt+P` 拍照。
- 单实例：重复启动只唤起已有宠物。
- 开机自启：默认关闭；设置里开启，写当前用户 Run 项，不请求管理员。
- 无右键菜单，避免和桌面右键冲突；所有入口在托盘/设置。

## 4. 行为与动画

### 4.1 日常状态

| 状态 | 触发 | 表现 |
|---|---|---|
| 待机 | 默认 | 呼吸起伏、眨眼、偶尔东张西望、看向鼠标 |
| 行走 | 每 3–8 分钟，持续 10–40 秒 | 底部左右走、手臂/腿反向摆动、脚步音、边缘转身 |
| 坐下 | 间隔较久、用户长时间不操作 | 腿前伸、身体放低、手臂搭在腿上 |
| 睡觉 | 系统空闲 > 10 分钟或深夜 | 闭眼、低头、慢呼吸；用户回来时伸懒腰 |
| 伸懒腰 | 睡醒后/随机 | 双臂上举、身体后仰、头后仰、2.5s，回到待机 |
| 吃面包 | 每 8–20 分钟随机 | 掏出面包、啃 3–4 口、掉屑、咀嚼音、打嗝、爱心 |
| 火把 | 亮度低于阈值 / 长按 | 右手举火把，暖光照角色，火星，10–20s 自动收起 |
| 看鼠标 | 光标靠近 | 头部 yaw/pitch 跟随，限制角度 |
| 追鼠标 | 低频（慵懒性格，约 1/10 概率） | 朝光标方向小跑几步再停下 |
| 摸头 | 单击 | 歪头、闭眼、爱心、呼噜声 |
| 挥手/跳舞/转圈 | 每 10–20 分钟极低频 | 挥手、左右摇摆、原地转一圈 |
| 拖拽 | 按住 + 移动 | 四肢下垂、身体摆动；松手落地缓冲 |
| 全屏探头 | 检测到全屏 | 身体藏到边缘外，偶尔探头；见 §6 |
| 拍照 | Ctrl+Alt+P | 冻结当前姿态，截图后恢复 |

### 4.2 频率与性格

- 慵懒：默认每 **2–5 分钟**才有一个明显动作；走路不是一直走。
- 不做心情/饱食/精力数值；用系统空闲时间、亮度、随机计时驱动。
- 所有动作都可被拖拽/拍照/关闭打断，打断后平滑过渡，不瞬移。

### 4.3 动作质量要求

- 走路时手臂和腿自然反相摆动，身体有轻微上下起伏；不是平移贴图。
- 伸懒腰必须有：双臂上举、胸口打开、头后仰、脚底不离地。
- 坐下/睡觉必须改变腿和头的姿态，不能只是缩放。
- 所有状态切换用 150–300ms 平滑插值，避免跳帧。
- 眨眼用眼睑遮片实现，不换整张皮肤。

## 5. 火把与暗处

### 5.1 暗处判定

- 读取当前显示器亮度（Windows WMI `WmiMonitorBrightness`）。
- 亮度 ≤ 设置阈值（默认 **30%**）视为暗；阈值可在首次向导/设置中调（10–60%）。
- 读不到亮度时（部分台式机/外接屏）：不自动触发，保留手动长按；设置里显示“当前设备不支持亮度读取”。
- 自动火把：变暗时取出，持续 **12–18 秒**后放回；如果仍然暗，最多每 10 分钟再触发一次。
- 手动火把：原地长按 1.5s 切换；手动打开后一直保持，直到再次长按关闭或隐藏宠物。
- 自动与手动互不打架：手动状态优先；手动关闭后，下一次“变暗事件”才会再自动触发。

### 5.2 火把表现

- 右手持 Minecraft 火把模型，火把贴图来自本机 1.20.1 资源。
- 暖色点光只影响角色模型；**不做桌面暗角/全屏遮罩**。
- 火焰摇曳（光强/位置轻微噪声），火星粒子少量上升。
- 点燃：`fire/ignite.ogg`；熄灭：`block/candle/extinguish1.ogg`；燃烧时低音量循环 `fire/fire.ogg`。
- 火把状态下仍可走路、眨眼、看鼠标；不阻断其它动作。

## 6. 全屏探头

- 检测前台窗口是否覆盖某个显示器（边框/无边框全屏；排除桌面、任务栏、本应用）。
- 检测到全屏时：
  - 停止走路，身体沉到屏幕外，只露头。
  - 每隔 **20–45 秒**从**随机边缘**（上/下/左/右）探出一次，停留 4–8 秒，再缩回。
  - 探头时只显示头部附近，身体被窗口/画布裁掉；不挡游戏主画面。
  - 全屏结束后回到任务栏上方，继续正常走动。
- 检测失败/无权限时：不探头，宠物保持正常底部行为；日志记录原因。
- 多显示器：以全屏窗口所在显示器为准；宠物临时移动到该显示器边缘。

## 7. 关闭、粒子与托盘

- 长按 3s 触发关闭（不是退出进程）。
- 2.4s 起：紫色粒子在角色周围聚集（无进度条、无变色）。
- 3.0s：角色消失，粒子从角色位置向全屏扩散；末影人/传送门紫粒子，向上飘、带重力与拖尾。
- 粒子再保留 **约 1.2 秒**，然后窗口隐藏；托盘图标保留。
- 托盘“显示宠物”可恢复；托盘“退出”才退出进程。
- 关闭音效：末影人 portal + portal/travel 叠加，音量随主音量。
- 关闭动画期间窗口全屏但点击穿透，不拦截桌面操作。

---

## 8. 吃面包

- 每 8–20 分钟随机一次；行走/火把/拖拽/拍照时不触发。
- 从背后/物品栏位置掏出面包（右手持面包），举到嘴边。
- 啃 3–4 口；每口面包模型缩小一档，掉棕色面包屑粒子，播放猫吃食音（Minecraft `mob/cat/eat`）。
- 吃完打嗝（`random/burp.ogg`），头顶冒 2–3 个爱心粒子。
- 全程无文字、无饥饿数值。

---

## 9. 拍照模式

- 全局 `Ctrl+Alt+P`；托盘也有“拍照”。
- 冻结当前姿态和粒子；隐藏可能遮挡的设置窗口。
- 用 Electron `desktopCapturer` 截取宠物所在显示器，包含桌面背景和宠物。
- 保存到 `%USERPROFILE%\Pictures\NikoPet\Niko-YYYYMMDD-HHmmss.png`。
- 拍完恢复动画；不弹预览、不加水印、不写文字。
- 如果宠物正藏起来/探头，拍照时先临时显示在底部中央，拍完恢复。

## 11. 窗口 / 系统 / 设置

### 11.1 首次启动向导

- 尺寸滑块（80–500px，实时预览，默认 220）
- 昵称（仅用于托盘提示/照片文件名，**不显示在桌面上**）
- 音量（默认 40%）
- 长按切换火把的时长（默认 1.5s；关闭阶段固定再 +1.5s）
- 是否开机自启（默认关）
- 暗处检测灵敏度（亮度阈值，默认 30%）
- “跳过，使用默认值”

### 11.2 设置窗口

- 通用：尺寸、昵称、音量/静音、开机自启、重置位置
- 交互：长按时长、点击音效开关、拖拽手感说明
- 环境：暗处阈值、自动火把开关、当前亮度读取状态
- 拍照：保存目录、打开目录
- 关于：版本、素材来源/许可、日志位置、恢复默认

### 11.3 系统行为

- 单实例；第二次启动唤起宠物。
- 多显示器/DPI 变化后回到可用区域；记住上次显示器和位置。
- 隐藏后暂停渲染与走路；显示后恢复。
- 关掉设置窗口不影响宠物。
- 不写注册表（自启除外）；不联网；不发遥测。

## 12. 非目标
